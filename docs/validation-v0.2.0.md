新增 pricing 回归测试先在旧实现上运行，六项均因缺少费用字段 / 计算模块失败；实现后通过。前端测试先因缺少费率脚本失败，再验证实际渲染函数与事件处理。最终 56 项 Python 测试通过，两个 Node 前端交互测试通过；22 个 Python 文件的 3.9 语法及编译、两份 JavaScript、shell 语法和 Git diff 检查通过。

- 1,900 条缺少公开费率（1,898 条自动审核、2 条 unknown），明确从费用汇总排除；不是已确认零成本。
- 已定价部分按默认费率：88,709.83859 credits；API 等价估算 $6,039.7145686。两者是独立口径，包含明确的默认模式 / 长上下文假设，不代表实际账单。
