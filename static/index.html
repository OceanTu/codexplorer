每个 token，只计一次

总量 = 输入 + 输出。缓存输入是输入的子集，推理是输出的子集，不会再加到总量中。未缓存输入 = 输入 − 缓存读取输入；如有缓存写入，它也包含在未缓存输入中。

新版逐次记录：优先读取 token_usage_record，按 response_id 去重。旧版累计差分：从 token_count 的累计值还原；计数器重置或首次遇到继承值时只取 last_token_usage，并标记不确定项。旧版记录可能覆盖多次请求，因此“请求 / 记录数”不一定等于真实 API 请求数。

会话与 turn：按 session_id 汇总主代理、子代理与自动审核；按 root_turn_id 归并到主 turn。无法归属的历史记录单列。模型来自当时的 turn_context，缺失显示 unknown。

边界：只覆盖本机保留的日志。缺失日志、未记录的隐藏消耗和其他设备用量无法恢复。这里的 token 不是 ChatGPT 套餐额度百分比，也不是账单金额。图表使用服务所在电脑的本地日期。
